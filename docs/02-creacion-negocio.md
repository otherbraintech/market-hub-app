# Creación del Negocio

El primer paso en Market Ops es dar de alta el negocio (o marca personal) que se desea gestionar. El negocio actúa como el contenedor principal para toda la configuración y las órdenes de planificación posteriores.

## Parámetros del Negocio

Al crear un negocio, se definen los siguientes campos fundamentales:

-   **Nombre**: El nombre comercial del negocio.
-   **Descripción**: Una breve explicación de a qué se dedica la empresa.
-   **Tipo de Negocio**: Clasificación del modelo de negocio:
    -   *Empresa*
    -   *Marca Personal*
    -   *Ecommerce*
    -   *Agencia*
-   **Objetivos Generales**: Qué busca lograr el negocio a largo plazo (ej. "Ser referente en el sector de salud").
-   **Propuesta de Valor**: Qué hace único al negocio y por qué los clientes deberían elegirlo.
-   **Imagen/Logo**: Identidad visual básica para reconocimiento interno.

## Importancia de este Paso

Este paso establece el contexto general. Sin un negocio creado y seleccionado, no es posible acceder a la configuración detallada ni a las herramientas de planificación.
